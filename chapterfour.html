04 Chapter 4 / The 2010s

Mobile & responsive design

The web learns to fit in your pocket, and on almost any other screen.

2010

One website, many screens

As phones and tablets became common ways to browse, a layout made only for a desktop monitor was no longer enough. Text needed to remain readable, images needed to fit, and navigation needed to work in less space.

In his 2010 article, Ethan Marcotte described responsive web design using fluid grids, flexible images, and media queries. A page could adapt to the available space instead of requiring a separate design for every device.

The 2010s

Start small, then build outward

A mobile-first approach begins with the essential content and layout for a small screen. As more space becomes available, the design can add columns, wider images, or other useful changes.

The goal is not simply to shrink a desktop page. It is to make the content, navigation, and controls work well wherever someone opens the website.

A simple responsive rule

/* Stack the columns on smaller screens. */
@media (max-width: 700px) {
  .page-layout {
    grid-template-columns: 1fr;
  }
}

Try it on this page

Make your browser window narrower. The reading area and chapter guide stack, while the navigation wraps to fit the screen.
