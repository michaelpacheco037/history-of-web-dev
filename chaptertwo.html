02 Chapter 2 / 1995–1998

Dynamic web content

JavaScript and CSS give webpages behavior and a style of their own.

1995

Pages start responding

JavaScript was created by Brendan Eich at Netscape in 1995. It gave developers a way to respond to actions in the browser, changing text, checking forms, or updating a page after a button click.

Server-side tools such as CGI, Perl, and PHP developed alongside browser scripting. They handle work on a server, while browser JavaScript can change what the visitor sees. One did not simply grow out of the other.

1996–1998

Design gets its own language

W3C published CSS1 as a recommendation in December 1996, followed by CSS2 in May 1998. Style sheets let developers control colors, fonts, spacing, and other presentation choices separately from the HTML content.

A shared style sheet could give many pages the same appearance. Browser differences still made some effects difficult, but the separation of structure and presentation became a lasting part of web development.
